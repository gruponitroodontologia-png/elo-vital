dentro do repositório do Grupo Nitro. Aqui cada mudança fica registrada com
data e motivo, e nada se perde.

## Onde fica cada coisa

- **Aqui no Code (esta pasta):** a versão oficial do plano e dos projetos.
  Toda decisão nova entra aqui.
- **No Claude Docs:** documentos que a equipe edita junto, como a tabela dos
  podcasts. O Plano Odisseia continua lá como cópia de leitura de
  12/10/2026; a partir de 03/11/2026, a versão que vale é a desta pasta.
- **No Google Drive:** os arquivos originais do Permanecer no Cuidado
  (fev/2026), preservados como estavam.

## Como pedir uma mudança

É só dizer, em qualquer conversa aqui no Code, o que mudou ("o mastermind
foi marcado para dia 25", "tira esse podcast da lista"). A mudança é feita
no arquivo certo desta pasta e registrada com data.
